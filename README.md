# Feature_extraction_using_pandas

This repository contains a Jupyter Notebook that demonstrates feature extraction and basic data handling using Pandas.

## What the notebook covers

- Loading and inspecting the dataset
- Performing basic Pandas operations
- Extracting useful features from the data
- Preparing the data for further analysis
